# Hồ sơ tham khảo cục bộ

Hồ sơ đăng ký PSI2026 gốc chứa thông tin liên hệ cá nhân và được giữ nguyên trên máy làm việc. File gốc không được đưa vào repository GitHub công khai; các attachment trong thư mục này bị gitignore.

Tài liệu sản phẩm/kiến trúc ở các thư mục docs khác chỉ sử dụng bối cảnh dự án và phân công cần thiết, không sao chép số điện thoại, email, ngày sinh hoặc mã sinh viên từ hồ sơ.
